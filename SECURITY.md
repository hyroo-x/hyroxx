# Security Policy

## Hyroxx Security

The Hyroxx project takes security reports seriously. We appreciate responsible disclosures that help protect developers and users who rely on Hyroxx.

Hyroxx is an independently maintained fork based on WhiskeySockets/Baileys, with additional development focused on interactive messaging and button-related functionality.

## Supported Versions

Security fixes are considered for the latest published version of Hyroxx.

Older versions may not receive security updates. Users are encouraged to update to the latest version when a fix becomes available.

## Reporting a Vulnerability

If you discover a potential security vulnerability in Hyroxx, please report it privately to the project maintainer through a private contact channel listed in the repository or npm profile.

Please include:
- A clear description of the suspected vulnerability.
- The affected version and environment.
- Steps to reproduce the issue, where safe and appropriate.
- Potential impact and any relevant logs or evidence.

Please do not disclose vulnerabilities publicly until the maintainer has had a reasonable opportunity to investigate and address the issue.

## Sensitive Information

Never include the following in public issues, pull requests, or discussions:

- WhatsApp authentication credentials or session files.
- API keys, access tokens, passwords, or private keys.
- Personal information belonging to other people.
- Private messages or confidential account data.

If sensitive information is accidentally exposed, revoke or rotate affected credentials as soon as possible.

## Responsible Disclosure

The maintainer will review reports and may request additional information to verify the issue. Please allow reasonable time for investigation and remediation before public disclosure.

Not every report will necessarily result in a security update. Reports that cannot be reproduced or that fall outside the project's scope may require further clarification.

## Scope

This policy covers security vulnerabilities directly related to the Hyroxx project and its maintained modifications.

Issues originating in upstream dependencies may need to be reported to their respective maintainers as well.
