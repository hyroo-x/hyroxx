🧩 02. WHAT IS HYROXX?

Hyroxx is an independent Baileys fork based on the Baileys codebase, with custom modifications intended to expand interactive messaging capabilities.

The project retains the foundation of the upstream Baileys ecosystem while introducing custom development focused on interactive messages and button functionality.

🎯 Main Focus:

- 🔌 WhatsApp Web connection and automation
- 💬 Message sending and receiving
- 🧩 NativeFlow interactive message support
- 📋 CTA Copy button implementation
- ⚙️ Custom message pipeline development
- 🛠️ Flexible customization for bot developers

Hyroxx aims to provide developers with additional flexibility while retaining the foundation of the upstream project.

⚡ 03. NATIVE FLOW SUPPORT

NativeFlow is one of the main areas of customization in Hyroxx.

✨ Highlights:

📋 04. CTA COPY & EXPANDED BUTTON SUPPORT

HyroxX includes custom improvements to interactive messaging, expanding button support and giving developers more flexibility when building WhatsApp bots.

✨ Highlights:

- 🔘 Button message support
- 🧩 NativeFlow interactive message integration
- 📋 List message support
- 📨 Template message support
- 📋 CTA Copy button structure
- ⚙️ Custom message-generation and sending pipeline
- 🛠️ Flexible handling of interactive message structures
- 🚀 Extended customization for WhatsApp bot developers

HyroxX aims to provide a more flexible foundation for creating and experimenting with interactive WhatsApp messages, including supported button types and custom message structures.

⚠️ Actual rendering and behavior may depend on the message structure, WhatsApp client, and implementation used by the bot. Not every button type is guaranteed to work in every client.
